# Dr. Maya Reynolds — Assingment

## What is included
- `/` — redesigned final homepage.
- `/clone` — a separate clone/reference page showing the original Conejo Valley-inspired structure before redesign.
- Responsive desktop/mobile layout.
- New visual system: sage, deep green, cream, sand and clay.
- Rewritten homepage copy for the fictional Dr. Maya Reynolds profile.
- Services, About, FAQs, Contact and a custom “Our Office” section.
- Replaced imagery using intentionally selected Unsplash photography.
- `VIDEO_WALKTHROUGH_SCRIPT.md` — natural 5-minute demo script.
- `PROFILE_CONTENT.md` — content source used for the fictional profile.
- `SUBMISSION_CHECKLIST.md` — final submission checklist.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy
Push the repository to GitHub and import it into Vercel. The default Next.js settings work without additional configuration.

## Notes
The source assignment asks for a profile link for Dr. Maya Reynolds. The screenshots supplied for this build show the requirements but do not expose the full profile contents. To avoid inventing a real person's information, this implementation treats Maya Reynolds as the fictional therapist specified in the assignment and keeps the profile content clearly general. If the provided profile link contains specific credentials, modalities, fees, or exact office details, replace the corresponding values in `PROFILE_CONTENT.md` and `app/page.tsx` before submission.
